JavaScript Lab Programs
=======================

This folder contains programs for the requested JavaScript lab questions.

Files 1-20: Core JavaScript programs
Files 22-36: DOM and event-based HTML/JavaScript experiments
Files 38-47: Advanced JavaScript experiments
Files 48-67: Additional programming problems

Question 21 and Question 37 are section headings in the original list, not separate programs.

How to run:
- .js files: run with Node.js using `node filename.js`.
- .html files: open them in a web browser.
- API examples require an internet connection.
- localStorage example must be run in a browser context, not plain Node.js.

Each program uses simple examples so it can be easily modified for lab records.
